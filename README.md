# القرآن الكريم – تقريب القرآن

تطبيق ويب عربي لقراءة القرآن الكريم وعرض التفسير المتوفر من كتاب تقريب القرآن للسيد محمد الحسيني الشيرازي رحمه الله.

## التشغيل
- افتح index.html في متصفح حديث، أو انشر محتويات المستودع على GitHub Pages.
- لا يحتاج التطبيق إلى خادم خلفي أو حزم خارجية.
- البحث والمفضلة وتغيير حجم الخط وحفظ نص السورة تعمل محلياً.
- اضغط مطولاً على الآية لعرض التفسير.

## قاعدة البيانات
- 114 سورة و6,236 آية.
- النص القرآني بالرسم العثماني من مشروع Tanzil، منقول دون تعديل؛ راجع NOTICE-tanzil.txt.
- ملفات data-XX.js تقسم قاعدة البيانات لتسهيل صيانتها وتحميلها.
- فُصلت البسملة عن ترقيم الآيات في السور التي لا تُعدّ البسملة فيها آية، مع استثناء الفاتحة والتوبة.
- لا يعرض التطبيق نصاً تجريبياً عند نقص البيانات.
- بعض مواضع التفسير غير مدخلة بعد؛ يظهر تنبيه واضح بدلاً من تفسير مختلق.

## التحقق
شغّل: node scripts/validate-data.js
ويعمل التحقق تلقائياً عبر GitHub Actions عند تحديث main أو فتح طلب دمج.

## ملاحظة حول الصوت
المستودع الحالي لا يحتوي ملفات صوتية أو روابط صوتية للتفسير؛ لذلك تركز هذه النسخة على القراءة النصية والتفسير المتوفر ولا تعرض زر تشغيل صوتياً غير موصول بمصدر حقيقي.
